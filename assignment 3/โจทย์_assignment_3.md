## หัวข้อ

เขียนโปรแกรมสำหรับการ Train Multilayer Perceptron โดยใช้ Genetic Algorithms

## ชุดข้อมูล

ใช้ไฟล์ `wdbc.data` ซึ่งเป็น Wisconsin Diagnostic Breast Cancer (WDBC) จาก UCI Machine Learning Repository:

`https://myweb.cmu.ac.th/sansanee.a/IntroCI/dataset/wdbc.data`

รายละเอียดข้อมูล:

1. มี 2 classes
2. มี 30 features
3. แต่ละ sample มีทั้งหมด 32 ค่า
4. ค่า 1 คือ ID number
5. ค่า 2 คือ Diagnosis: `M` = malignant, `B` = benign
6. ค่า 3-32 คือ features ทั้ง 30 ค่า

## การทดลองที่ต้องทำ

- ใช้ 10% cross validation เพื่อทดสอบ validity ของ network ที่ได้
- ทดลองเปลี่ยนจำนวน hidden layer
- ทดลองเปลี่ยนจำนวน nodes ใน hidden layer
- เปรียบเทียบผลการทดลองและวิเคราะห์ผลอย่างเป็นระบบ

## องค์ประกอบของรายงาน

1. ลักษณะการทำงานของระบบ
2. Simulation ของระบบ ผลการทดลอง และการวิเคราะห์
3. โปรแกรม

## รูปแบบรายงาน

ให้จัดทำในรูปแบบรายงานจริงจัง โดยอิงโครงสร้างจากรายงาน Fuzzy Logic ของ Assignment 2 ไม่จำเป็นต้องตกแต่งมาก เน้นความชัดเจนของเนื้อหา วิธีทดลอง ผลลัพธ์ ตารางหรือกราฟที่เขียนขึ้นเอง และการวิเคราะห์ที่มีเหตุผล

## รูปแบบโปรแกรม

โปรแกรมควรแบ่งเป็นฟังก์ชันพื้นฐานที่อ่านง่าย เช่น การอ่านข้อมูล การเตรียมข้อมูล การคำนวณ MLP การฝึกด้วย Genetic Algorithm และการประเมินผล แต่ละส่วนควรมีคอมเมนต์ภาษาไทยหรือภาษาอังกฤษกำกับอย่างละเอียด เพื่อให้ผู้เขียนสามารถอธิบายลำดับการทำงาน สูตรที่ใช้ และความหมายของตัวแปรได้ด้วยตนเอง
