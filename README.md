# Computational Integration

รวบรวมงาน Computer Assignment ของวิชา Introduction to Computational Intelligence โดยมีทั้งโปรแกรมจำลอง Fuzzy Logic และการทดลอง Multilayer Perceptron (MLP) ด้วยวิธีการฝึกที่แตกต่างกัน

## รายการงาน

| Assignment | หัวข้อ | รายละเอียด |
|---|---|---|
| [Assignment 1](./assisgnment%201/README.md) | MLP และ Backpropagation | สร้าง MLP จาก Python standard library และทดลองทั้งการพยากรณ์ระดับน้ำท่วมและการจำแนกข้อมูล `cross.pat` |
| [Assignment 2](./assignment%202/README.md) | Fuzzy Logic | จำลองระบบ Mamdani Fuzzy Logic เพื่อควบคุมอุณหภูมิน้ำอาบ |
| [Assignment 3](./assignment%203/README.md) | MLP และ Genetic Algorithms | ฝึก MLP เพื่อจำแนกมะเร็งเต้านมจากชุดข้อมูล WDBC |
| [Assignment 4](./assignment%204/README.md) | MLP และ Particle Swarm Optimization | ใช้ PSO ฝึก MLP สำหรับพยากรณ์ค่า Benzene จากข้อมูลคุณภาพอากาศ |
